# ECOLIFE DIGITAL EXPERIENCE

This repository represents the official Ecolife website.

For every design or frontend task, treat these files as mandatory project rules:

- .gemini/skills/ecolife-art-direction/SKILL.md
- .gemini/skills/ecolife-anti-slop/SKILL.md
- .gemini/skills/ecolife-motion-3d/SKILL.md
- .gemini/skills/ecolife-frontend-quality/SKILL.md
- design-system/ECOLIFE-DESIGN-SYSTEM.md
- design-system/MOTION-SYSTEM.md
- design-system/ANTI-SLOP-CHECKLIST.md

Core principle:

LIGHT IS ARCHITECTURE.

Never reduce Ecolife to a generic modern website.

Before major design implementation:

1. inspect the existing context
2. identify the page's visual focal point
3. define its primary spatial composition
4. define whether interaction adds meaning
5. implement
6. visually inspect the rendered result
7. perform anti-slop audit
8. refine again

Never stop at the first aesthetically acceptable result.

The visual quality bar is exceptionally high.
