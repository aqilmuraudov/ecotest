# ECOLIFE ANTI-SLOP VISUAL QA CHECKLIST

Every page, component, and interaction must pass this 10-point audit before completion:

- [ ] **1. No Rounded-2XL / Rounded-3XL Containers**: Are cards and layout blocks structured with crisp architectural corners (`rounded-none`, `rounded-sm`, or max `rounded`)?
- [ ] **2. Zero Static Pill Enclosures**: Are metadata tags (categories, years, dimensions, codes) rendered as clean unboxed text separated by `·` or `/` rather than capsule badges?
- [ ] **3. Yellow is Emitted Light, Not Surface Paint**: Is brand yellow used strictly for illumination, active states, and primary focal actions? Have decorative yellow icons and yellow outlines been removed?
- [ ] **4. Rhythm Over Card Repetition**: Do adjacent sections vary in visual composition (e.g. Asymmetric 7/5 split $\to$ Full-width photographic chapter $\to$ Precision technical specification grid) instead of repeating identical 3-column card rows?
- [ ] **5. Legitimate Technical Details**: Are product dimensions, CRI, Kelvin, voltages, and profiles authentic to real architectural lighting specifications? (No fake telemetry or sci-fi hud clutter).
- [ ] **6. No Gradient Blobs or Purple Hues**: Is the background clean obsidian `#08090A` / charcoal `#0E1013` without muddy purple/blue AI gradient blobs or generic glassmorphism?
- [ ] **7. Controlled Typography Contrast**: Does the page use dramatic scale contrast between monumental display headers and crisp monospace drafting annotations?
- [ ] **8. Photographic Viewport Presence**: Do real architectural project photographs and fixture textures command generous breathing room instead of being trapped in small thumbnails?
- [ ] **9. Interactive Kelvin / CCT Instrument**: Does the lighting temperature interaction feel like a physical photometric instrument with authentic color rendering?
- [ ] **10. Functional Integrity**: Do all routes, languages (AZ / EN / RU), theme switches, catalog filters, product modals, search dialogs, and contact forms function seamlessly without breakage?
